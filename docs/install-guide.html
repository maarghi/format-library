Save to My Formats

Install guide for the Virio team

This browser extension adds a ➕ My Formats button to LinkedIn posts. Click it to save a post — text, image, funnel stage, labels, a note — into the team's shared Format Library. Pick whichever install method applies, then do the one-time setup at the bottom.

Option A — Chrome Web Store Easiest

Status: pending Google review. Once it's approved, this is a one-click install. Marghi will drop the link here:

Install from the Chrome Web Store →  (link coming after approval)

  1. Open the link above in Google Chrome.
  2. Click Add to Chrome → Add extension.
  3. Done — skip to First-time setup below.

It's an unlisted listing, so it won't show up in search — you can only install it from the link.

Option B — Load it manually Works right now

Use this until the store version is approved. Takes about 2 minutes.

  1. Download the files: click here to download the ZIP (from the GitHub repo).
  2. Unzip it. You'll get a folder named format-library-main. Inside it is a folder called swipe-file-extension — that's the one you need.
  3. In Chrome, go to chrome://extensions (type it in the address bar).
  4. Turn on Developer mode (toggle, top-right).
  5. Click Load unpacked (top-left) and select the swipe-file-extension folder.
  6. The extension appears in your toolbar. If you don't see the frog icon, click the puzzle-piece 🧩 and pin Save to My Formats.

Keeping it updated: when there's a new version, re-download the ZIP, replace the folder, then hit the reload ↻ on the extension's card in chrome://extensions. (The store version, Option A, updates itself automatically.)

First-time setup

  1. Click the Save to My Formats icon in your Chrome toolbar.
  2. Enter the team code: virio-frogs  (ask Marghi if this changes)
  3. Pick or type your name — your saves land in your own tab in the shared sheet.
  4. Open LinkedIn. On any post, click the ➕ My Formats button, choose a funnel stage & labels, and hit Save.

Tip: if you just installed or reloaded the extension, refresh any LinkedIn tab you already had open (⌘+Shift+R) so the button appears.
